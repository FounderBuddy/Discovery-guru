# ADR 0005 — Escalate every practice-vs-client conflict

**Status:** accepted

**Context.** Recommendations draw on Datatonic practices, researched best practice, and client rules.
These can contradict each other.

**Decision.** No automatic precedence. Every conflict between a client rule and a practice becomes an
escalated decision for the solution owner; the recommendation stays blocked until all are decided.

**Consequences.** The owner sees every trade-off explicitly and the decision log shows why each choice
was made. Busy engagements may produce many escalations; batching them in the UI is a likely next step.
